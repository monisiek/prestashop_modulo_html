# Modulo HTML Homepage per PrestaShop

## Descrizione

Questo modulo permette di visualizzare contenuto HTML personalizzato nella homepage del tuo negozio PrestaShop.

## Caratteristiche

- Visualizza contenuto HTML personalizzato nella homepage
- Editor HTML integrato nel pannello di amministrazione
- Possibilità di abilitare/disabilitare il modulo
- Supporto per tutti i contenuti HTML (testo, immagini, link, ecc.)

## Installazione

1. Carica la cartella `htmlhomepage` nella directory `modules` del tuo negozio PrestaShop
2. Vai nel pannello di amministrazione PrestaShop
3. Vai su **Moduli > Gestore moduli**
4. Cerca "HTML Homepage"
5. Clicca su **Installa**

## Configurazione

1. Dopo l'installazione, clicca su **Configura**
2. Abilita il modulo usando l'interruttore "Abilita modulo"
3. Inserisci il contenuto HTML che vuoi visualizzare nella homepage
4. Clicca su **Salva**

## Utilizzo

Il contenuto HTML inserito verrà visualizzato automaticamente nella homepage del negozio, utilizzando l'hook `displayHome`.

## Requisiti

- PrestaShop 1.7 o superiore
- PHP 7.1 o superiore
